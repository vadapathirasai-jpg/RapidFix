═══════════════════════════════════════════════════════════════════════════

FASTEST WAY (5 minutes):

1. Get AWS Credentials
   └─ Go to https://console.aws.amazon.com
   └─ Create Access Key in IAM → Users → Your User → Security Credentials
   └─ Copy Access Key ID and Secret Access Key

2. Configure AWS
   $ aws configure
   (Enter credentials when prompted)

3. Setup Backend
   $ cd backend
   $ cp .env.example .env
   (Edit .env with your AWS credentials)

4. Install Dependencies
   $ npm install aws-sdk

5. Run Setup Script
   $ node setup-dynamodb.js
   
   Expected Output:
   ✓ Table Users created successfully!
   ✓ Table Technicians created successfully!
   ✓ Table Bookings created successfully!
   ✓ Table Reviews created successfully!
   ✓ Table Services created successfully!
   ✓ Table Verifications created successfully!
   ✓ Table Notifications created successfully!

DONE! All 7 tables created in your AWS account.

HOW IT WORKS:

     ↓                 ↓

     ↓                 ↓

     ↓                 ↓

COMMON ISSUES:

❌ "Credentials not found"
   $ aws configure

❌ "UnrecognizedClientException"
   Check AWS Access Key and Secret Key

❌ "ValidationException"
   Make sure region is us-east-1

❌ "Table already exists"
   You can run the script again - it skips existing tables

═══════════════════════════════════════════════════════════════════════════
